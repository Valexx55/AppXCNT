# 📱 Recursos de Desarrollo de Aplicaciones Android

Este repositorio recopila **enlaces oficiales y recursos de referencia** utilizados durante el aprendizaje y desarrollo de aplicaciones Android. Incluye documentación de Android Developers, Firebase, Material Design, Kotlin, APIs externas y certificaciones oficiales.

El objetivo es servir como **guía centralizada** para estudiantes y desarrolladores Android, tanto en formación como en proyectos reales.
